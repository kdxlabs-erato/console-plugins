The project made for HR has a mark of its own: the icon pack's `people` on green. The form that enables the plugin begins the project to make with it, beside the icons and the colours to choose from, and `console plugin hr enable --board new` sends it as named. A project that exists, chosen at enabling or made before, keeps its own mark: change it in the project's settings.

The manifest names the mark in `board.defaults`, which a console reads from 0.6.1 and an older one refuses, so this version runs on console 0.6.1 or later, before 0.7.0.
